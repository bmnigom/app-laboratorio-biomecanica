# Reglas del Proyecto Laboratorio Biomecánica
- **Frontend:** Angular (carpeta `/frontend`). Estilos en SCSS.
- **Backend:** Python con FastAPI (carpeta `/backend`). Entorno gestionado con Conda (`lab_biomecanica`).
- **Regla Clínica:** La captura de datos debe seguir el orden posicional: Bípedo, Supino, Prono, Sedente, Bípedo.
- **Procesamiento de Video:** Los scripts deben enfocarse en recortar y anonimizar rostros mediante OpenCV antes de guardar.
